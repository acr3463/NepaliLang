## 💡 What is NepaliLang?

NepaliLang is a modern, Python-inspired programming language created in Nepal by Diwas Khatri. It's designed to make programming education accessible to everyone in Nepal by using Nepali keywords instead of English ones. Imagine writing code that looks like this:

```
प्रिन्ट("नमस्ते संसार!")
```

That's NepaliLang in action! It's perfect for students, teachers, and anyone who wants to learn programming without struggling with English syntax.
